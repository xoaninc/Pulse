# Kit de música para el Echo Mini

Prepara música y playlists `.m3u8` para un Snowsky / FiiO Echo Mini con el firmware V4.0.0.

- `CLAUDE.md`: contexto, reglas del aparato y forma de trabajar (lo lee Claude Code al abrir esta carpeta).
- `CHECKLIST.md`: comprobaciones en orden, hasta la prueba en el aparato.
- `echomini_tool.py`: `scan`, `lrc`, `playlist` y `covers` (`python echomini_tool.py -h`).
- `echomini_config.json`: límites y carpetas.
- `ejemplos/`: lista en texto, CSV de Exportify y una letra `.lrc`.

La música va en `EchoMini/` dentro de esta carpeta. Está en `.gitignore`, así que nunca se sube.
